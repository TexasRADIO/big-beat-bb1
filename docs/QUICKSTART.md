# First play

BB1 is firmware for the FM-1. This is a development guide; use the instructions for your installed version.

1. Begin with output low. Tap and release **HOME** for Studio. Turn **SELECT** to focus a drum layer or Dillo, then press **EDIT** to open it.
2. Press **PRESETS** to browse kits or sounds. Press **EDIT** to confirm.
3. Press **ALGORITHM** to browse patterns or bass phrases. Let the knob settle, then press **EDIT** to confirm.
4. Press **PLAY** to start or stop. On PATTERN while stopped, PLAY confirms the highlighted pattern before starting if needed. Check **LOADED KIT** and **PLAYING**, then bring the output up gently.

A browsing choice can still be waiting. Selected, queued, loaded and playing describe different stages. Follow the screen’s confirmation prompt and current knob labels.

| Control | Action |
| --- | --- |
| HOME | Tap and release for Studio; hold for help |
| SELECT / EDIT | Focus an instrument / open it; EDIT confirms KIT/PATTERN |
| PRESETS | Browse sounds or kits |
| ALGORITHM | Browse patterns or phrases |
| FX | Open effects; EDIT cycles their pages |
| REC + FX | Throw gesture; release FX to end it when supported |
| GLO | Open GLOBAL: BPM, swing, A/B balance and transpose |
| REC + SELECT | Hold REC and turn SELECT for tempo |

Studio’s four knobs are A level, B level, Dillo level and FX return. MASTER controls overall output. Dillo’s main page has cutoff, resonance, envelope amount and decay; other pages show their own assignments.
